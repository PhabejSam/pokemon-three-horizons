# Jessie and James — monicaccina

Original art: **monicaccina** (formerly Ody-chan), “GBA Jessie and James,” 2013.

Source: https://www.deviantart.com/monicaccina/art/GBA-Jessie-and-James-353030680

The artist's public description explicitly permits reuse, including without
credit; verified on 2026-09-27. Three Horizons credits monicaccina anyway, as
requested by the user. The author also confirms permission in the page comments.

`monicaccina-original.png` preserves the downloaded 155×66 RGBA source sheet.
`tools/three_horizons/import_rocket_art.py` crops and rearranges the nine walking
frames into the engine's 16×32 standard animation order, centers each separate
battle portrait on a 64×64 canvas, and converts each image to 15 visible colors
plus transparent index zero. East-facing frames use the engine's native mirror.
The creator's signature remains in the original sheet and this attribution.

No normal Rocket grunt graphics are replaced. The two unused doll graphics
slots are aliased only in the Three Horizons build, preserving all existing
object graphics, dynamic graphics and follower IDs across normal save upgrades.
